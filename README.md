# 作品集

## 資策會專題 - 登山網站 找靠山

---

找靠山 是一個整合登山資訊並提供相對應山的難易度裝備給使用者選擇，其中透過==製作個人化明信片==，讓網站增加和使用者的互動效果。

### 1. 前台

- 使用 HTML Drag and Drop API 實現商品拖曳至明信片處功能
- 使用 fabric.js (javascript canvas 函式庫)，實現在明信片內，進行諸如曳、旋轉和變形等等效果
- 使用 html2canvas 套件，實現儲存明信片功能
- 串接第三方 API ，實現使用社群 Facebook, Twitter, Line 分享功能

[Demo](tzulingtseng.github.io/portfolio/template-find-mountain/outfit/outfit.html) |
[GitHub 程式碼](https://github.com/tzulingtseng/tzulingtseng.github.io/blob/main/portfolio/template-find-mountain/outfit/outfit.html) |
[GitHub React.js + Node.js 程式碼](https://github.com/tzulingtseng/find-mountain)

![](https://i.imgur.com/GZtET4f.jpg)

### 2.後台

- 主要負責評論和檢舉的新增、讀取、更新、刪除功能
- 使用 PHP 對 MySQL 進行 CRUD 操作
- 使用 AJAX 串接前後端
